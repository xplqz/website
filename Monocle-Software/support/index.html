TOURDY투어디 자주 묻는 질문

로그인하지 않으면 기록이 사라지나요?

로그인하지 않아도 모든 기본 기능을 쓸 수 있고 기록은 기기에 저장됩니다. 다만 앱을 지우거나 기기를 바꾸면 복원할 수 없으니, 기록을 지키려면 로그인해 두는 것을 권해요.

투어디 플러스 구독은 어떻게 해지하나요?

iPhone은 설정 → Apple ID → 구독, 안드로이드는 구글 플레이 → 결제 및 정기 결제 → 정기 결제에서 해지할 수 있습니다. 해지해도 이미 결제한 기간이 끝날 때까지 혜택이 유지됩니다.

환불은 어떻게 받나요?

결제는 Apple·구글이 처리하므로 환불도 각 스토어에서 신청합니다. iPhone은 reportaproblem.apple.com, 안드로이드는 구글 플레이의 주문 내역에서 신청할 수 있어요.

계정을 삭제하고 싶어요.

앱의 설정 → 계정 → 계정 삭제를 누르면 서버에 저장된 기록이 바로 삭제됩니다. 앱에 들어갈 수 없다면 가입한 소셜 계정 종류와 함께 이메일로 요청해 주세요. 유료 구독은 계정 삭제와 별개로 스토어에서 해지해야 합니다.

주간 챌린지 결과가 ‘확인 중’으로 떠요.

기록이 평소와 크게 다르면 결과와 보상을 최대 7일 동안 보류하고 자동으로 확인합니다. 정상 기록이면 확인이 끝나는 대로 반영돼요. 직접 추가한 기록은 챌린지에 반영되지 않습니다.

기기 두 대의 기록이 다르게 보여요.

두 기기 모두 같은 계정으로 로그인했는지 확인한 뒤 앱을 다시 열어 보세요. 그래도 다르면 두 기기의 앱 버전과 함께 알려 주세요.
